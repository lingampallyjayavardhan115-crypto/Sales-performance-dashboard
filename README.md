# Sales-performance-dashboard
This Tableau project is designed to track and analyze sales performance metrics. It connects to an Excel data source named sample-data-10mins.xlsx. The underlying dataset tracks transactions using fields such as Sales Person, Country, Product, Date, Amount, and Boxes Shipped. The workbook also includes a custom calculated field named Shipment Count to track the number of shipments.  

The project consists of three individual worksheets that are combined into one main interactive dashboard:  Sales by Country: A geographic breakdown showing total sales amounts distributed across various countries (including Australia, UK, India, USA, Canada, and New Zealand).  Top 10 sales: A bar chart that highlights the top-performing sales representatives by filtering for the top 10 individuals based on their total sales amount. 

Business summary: A high-level text table displaying overarching key performance indicators (KPIs), specifically the total Amount, total Boxes Shipped, and the Shipment Count.  Dashboard 1: The final dashboard consolidates these three views. It features interactivity, including an action filter that allows users to click on a specific country in the "Sales by Country" sheet to dynamically filter the "Top 10 sales" and "Business summary" data for that specific region.
